# Student Registration System

A Flask-based web application for managing student registration and information at K.L.E. Society's Jagadguru Tontadarya College, BCA Program.

## Features

- **Student Management**: Add, edit, view, and delete student records
- **Student Details Tracking**: Store comprehensive student and parent information
- **Dashboard & Analytics**: Visualize student distribution across semesters with Chart.js graphs
- **Responsive Design**: Bootstrap-based UI inspired by the college's branding
- **Database Management**: SQLite database for persistent data storage
